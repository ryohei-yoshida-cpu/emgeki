# 演劇脚本ノート

スマートフォンで演劇の脚本を書き、A4で印刷（PDF保存）できるWebアプリです。
インストール不要で、ホーム画面に追加すればアプリのように使え、オフラインでも動きます。

## 使い方

アプリ内の **使い方ガイド**（`guide.html`。☰・設定・書き始めの画面から開けます）に、画面ごとの説明とよくある質問をまとめています。

### 書く（「脚本」タブ）
画面下のボタンで段落を追加します。

| ボタン | 動き |
| --- | --- |
| **セリフ** | 話す人物を選ぶと `名前「　」` の段落ができます。改行しても同じセリフ（段落）のままです。会話の流れから「次はこの人？」を先頭に出します。 |
| **ト書き** | 動き・情景の説明。位置（上部／2字下げ／3字下げ）は設定で選べます。 |
| **シチュエーション** | 前の行から1行あけて、中央配置の行になります。続けて「セリフ」を押すと通常のセリフに戻ります。 |
| **章立て** | `1章`、`2章`…と自動で番号が付き、右上詰めで配置されます（章ごとの改ページも可）。 |

- 空の段落でボタンを押すと、その段落の種類が切り替わります。
- 空の段落で Backspace を押すと段落が消えます。
- 各段落の「⋯」から、人物の変更・種類の変更・移動・削除・上への挿入ができます。
- 上部の ↶ で直前の操作を元に戻せます。

### 名前（「人物」タブ）
登場人物の名前はここで一括管理します。名前を変えると、脚本中の全セリフに反映されます
（本文中に書いた名前も、確認のうえ一括で置き換えられます）。
漢字の名前には **読み仮名が自動で付き**、印刷時にルビとして表示されます（毎回／初登場のみ／なし）。
読みが違う場合は直接書き換えられます。

### キャスティング（「配役」タブ）
役と演じる人を紐付けます。1人で複数の役を担当できます。
配役表は印刷時に表紙の次のページとして付き、演者ごとのセリフ数・出番の章も確認できます。

### 誤字・脱字チェック（「校正」タブ）
よくある誤字・誤変換、「変わるる」「私はは」のような余分な文字や重複（辞書による文法解析）、同じ人物のセリフの連続（「違う人物では？」→ワンタップで変更）、助詞や句読点の重なり、括弧の閉じ忘れ、セリフの空欄、人物名の打ち間違い、
半角カナ、ら抜き言葉などを調べ、ワンタップで修正できます（まとめて修正・無視も可）。
すべて端末内で処理するので、脚本が外部に送られることはありません。

### 印刷（「印刷」タブ）
- A4の **縦向き／横向き**、**縦書き／横書き** を選べます。
- 「印刷 / PDF保存」から印刷、またはPDFとして保存できます
  （iPhone：共有 → プリント、Android：印刷 → PDFとして保存）。
- フォント・文字サイズ・行間・表紙・ページ番号は「設定」タブで変更できます。

### メモと演技の指示
各段落（セリフ・ト書き・シチュエーション）の右の「⋯」から **「メモを追加」「演技の指示を追加」** ができます（ふだんは表示されません）。
指示の例：怒りをこらえて／スポットライトで照らす（照明・音響のきっかけにも使えます）。

印刷では、本文の **上（横書きでは左）にメモ**、**下 約1/5（横書きでは右）に演技の指示** のスペースができ、
本文との境には罫線（1本線）が入ります。書いた内容は、その段落と同じ列（同じ高さ）に入ります。
大きさや境の線は「設定 → 演者用の書き込み」で変えられます。Word・テキストでは段落の下に［メモ］［指示］として入ります。

### 話す人物の選び方
「セリフ」を押すと人物を選べます。ほかに次の選び方があります。

| ボタン | 内容 |
| --- | --- |
| 複数人を選ぶ | 同時に話す人物を何人でも選べます（「教授・裕二「…」」と表示） |
| 全員 | 「全員「…」」になります |
| モブ／脇役／群衆／煽り | 名前（例：通行人A、村人たち）を付けて使えます。「配役に追加」にチェックしたときだけ配役表・配役タブに出ます |

### 書く向き
「設定 → 脚本画面（書くとき）」で、書く画面を **縦書き／横書き** から選べます（台本に合わせて縦書きで書けます）。
印刷の向きとは別に選べます。縦書きでは、書いている列を画面の右側に寄せられるよう、最後の列のあとにも余白があります。

### 過去の脚本をPDFから読み込む
左上の ☰（または「設定」）の「PDFから読み込む」から、2つの方式を選べます。

| 方式 | 内容 |
| --- | --- |
| **PDFモード** | 元のPDFをそのまま端末に保存します。左上の ☰「脚本を切り替える」（PDFの印付き）や右上の「⋯」から選ぶといつでも読めます（拡大・縮小可、編集は不可）。 |
| **PDF＋修正モード** | PDFの文字を読み取り、人物・セリフ・ト書き・章・演技の指示を新しい脚本として取り込みます。元のPDFも保存され、「⋯」から見比べられます。 |

PDF＋修正モードは、レイアウトが崩れたり正しく取り込めない場合があるため、取り込み前と取り込み後に注意を表示します。
「名前「セリフ」」「名前：セリフ」「名前　セリフ」の形や、縦書き・横書きに対応しています。
文字情報のないPDF（紙をスキャンした画像など）は取り込めないため、PDFモードでの保存を案内します。

### 保存
入力のたびに端末内へ自動保存され、画面を閉じたりアプリを終了しても内容は残ります。
複数の脚本は左上の ☰ から切り替えられます。機種変更に備えて「設定 → バックアップを書き出す」も使えます。

### 共有書き出し（LINE・ドライブ保存）
右上の「⋯」→「共有書き出し」で、このアプリのデータ・Word・テキストのいずれかを選び、共有メニューから LINE で送ったり、Google ドライブ・MEGA・「ファイルに保存」などで保存先を選んで保存できます。共有メニューが使えない環境では、保存先を選ぶ画面（パソコンの Chrome・Edge など）か通常の保存になります。

### ファイルに保存（テキスト・Word）
左上の ☰ または「設定」から、脚本を **テキスト（.txt）** や **Word（.docx）** で保存できます。
Word ファイルには表紙・配役表・ルビ・章・ページ番号が入り、縦書き／横書き・用紙の向きも設定どおりになります。
iPhone では共有メニューが開くので「"ファイル"に保存」などを選んでください。

## 公開方法（GitHub Pages）
ビルド不要の静的ファイルのみで構成されています。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を **Deploy from a branch**、ブランチとフォルダ（`/ (root)`）を選んで保存
3. 表示されたURLをスマートフォンで開き、「ホーム画面に追加」

ローカルで試す場合は `python3 -m http.server` などで配信して `http://localhost:8000/` を開きます。

## 構成
```
index.html            画面
css/app.css           見た目と印刷レイアウト
js/app.js             画面の動き
js/store.js           保存（localStorage）
js/paginate.js        A4ページへの割り付け（縦書き・横書き）
js/proofread.js       誤字・脱字チェック
js/furigana.js        読み仮名の自動取得
js/fonts.js           フォント
js/export.js          テキスト・Word への書き出し
sw.js                 オフライン対応
js/pdfjs.js           PDF の読み込みと文字の取り出し
js/pdfparse.js        PDF の文字を脚本（セリフ・ト書き・章など）に読み替え
js/pdfstore.js        取り込んだ PDF の保管（IndexedDB）
vendor/kuromoji/      形態素解析ライブラリと辞書（Apache License 2.0）
vendor/pdfjs/         PDF.js 4.10.38 legacy 版（Apache License 2.0）
```
